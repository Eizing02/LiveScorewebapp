# Impeccable สำหรับ Football Prediction AI

ติดตั้งและปรับใช้วันที่ 27 ตุลาคม 2026 ใน `D:\Football Prediction AI` เท่านั้น

## รุ่นและวิธีติดตั้ง

- npm package: `impeccable@4.8.0`
- ต้นทาง: https://github.com/pbakaus/impeccable และ https://impeccable.style/docs/
- ใช้คำสั่งตามที่ผู้ใช้ร้องขอ โดย pin รุ่นให้ทำซ้ำได้:

```powershell
cd 'D:\Football Prediction AI'
npx --yes impeccable@4.8.0 install --providers=codex --scope=project --yes
```

ติดตั้งที่ `.agents/skills/impeccable/` พร้อม Windows engine และสร้าง `.codex/hooks.json` ไม่เพิ่ม dependency เข้า runtime ของเว็บไซต์ ไม่ติดตั้งทับโครงการ `D:\Live score Project`

รุ่นนี้เป็น **หนึ่ง skill ที่มี 24 workflows** ไม่ใช่ 24 คำสั่ง npm สำหรับแก้หน้าเว็บโดยตรง เวลาสั่งงานใน Codex ใช้ `$impeccable` ตามด้วยงาน เช่น `$impeccable audit apps/web/src` ส่วน CLI `detect`, `install`, `hooks` เป็นเครื่องมือประกอบ

ให้เปิดโปรเจกต์ใหม่นี้และรีสตาร์ต Codex เพื่อให้ค้นพบ skill ในแค็ตตาล็อกอัตโนมัติ รอบที่ติดตั้งนี้อ่านและใช้ skill จากไฟล์โดยตรงแล้ว

## ฟังก์ชันทั้งหมด และการนำมาใช้

คำว่า “ใช้แนวทาง” ด้านล่างหมายถึงอ่าน playbook แล้วนำขั้นตอนที่เหมาะกับงานมาปรับใช้ ไม่ได้หมายความว่าเรียก 24 คำสั่งอัตโนมัติครบทุกตัว บางตัวเป็นทางเลือกที่ขัดกัน หรือจำเป็นต้องให้ผู้ใช้เลือกภาพก่อน

## เครื่องมือประกอบ

- `detect`: ตัวตรวจเชิงกฎ 62 rules ในรุ่นที่ติดตั้ง รายงานอัตโนมัติไม่ทดแทนการดูหน้าจอและทดสอบการใช้งาน
- `hooks on/off/status`: ตั้งค่าตัวตรวจหลังแก้ UI และก่อนจบงาน
- `ignore-rule`, `ignore-file`, `ignore-value`: ยกเว้นกฎเมื่อมีเหตุผลเฉพาะเจาะจง รอบนี้ไม่ได้ปิดกฎเพื่อให้ผลตรวจผ่าน
- `pin/unpin`: สร้างหรือลบ shortcut ของ workflow ใน Codex; ยังไม่สร้าง shortcut ครบชุดที่อาจชนกับชื่อ skill อื่น
- `doctor`: ตรวจความสอดคล้องของไฟล์บริบทและ hook; ใช้เมื่อมีการย้ายหรืออัปเกรด ยังไม่ได้สั่งซ่อมโครงสร้างอัตโนมัติโดยไม่จำเป็น
- `install`, `link`, `check`, `update`: จัดการการติดตั้งและรุ่น ไม่ใช่การ build/deploy เว็บไซต์
- `telemetry`: ปิดไว้ด้วย `telemetry=false` ใน config ของโครงการ

ตัวอย่างตรวจ source ด้วย PowerShell:

```powershell
cd 'D:\Football Prediction AI'
& '.\.agents\skills\impeccable\scripts\impeccable.cmd' detect apps/web/src --json
```

Hooks ถูกติดตั้งและเปิดใน config โครงการแล้ว แต่การยอมรับ hook ของ Codex เป็นอีกชั้นหนึ่ง ต้องตรวจที่ Settings → Hooks เมื่อแอปพบ definition ใหม่ ไม่ได้แก้ไฟล์ความเชื่อถือของแอปแทนผู้ใช้ รอบนี้ใช้ detector ด้วยตนเองเพื่อไม่อ้างว่ามี hook ทำงานโดยที่ยังไม่ได้สังเกตจริง

## คำสั่งที่แนะนำสำหรับงานถัดไป

```text
$impeccable harden หน้ารายคู่เมื่อ API ส่งข้อมูลผู้เล่นหรือ lineup ไม่ครบ
$impeccable audit apps/web/src
$impeccable polish หน้าคู่เด่นและผลการทำนาย
$impeccable adapt หน้ารายคู่สำหรับมือถือ
```

เมื่อปรับ UI ต้องใช้ PRODUCT.md, DESIGN.md และ `.impeccable/surfaces/football-app.md` เป็นบริบท และรักษานโยบายข้อมูล/โมเดลเดิมไว้ การปรับภาพไม่ใช่เหตุผลให้เปลี่ยนผลทดสอบ เพิ่มเปอร์เซ็นต์ความแม่นยำ หรืออนุมัติโมเดล
