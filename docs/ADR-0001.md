# ADR-0001 — Separate prediction project

Accepted for local development, 2026-10-25.

Create D:/Football Prediction AI independently of the Express/MongoDB project at D:/Live score Project. No changes or database connections to the old project.

React/TypeScript renders a Thai dashboard. A Worker exposes stored, read-only public routes; D1 stores bounded current fixtures, feature snapshots, model metadata, immutable predictions, evaluations, usage and job state. Python performs historical ingestion, chronological features, CPU training/evaluation and batch inference. GitHub Actions handles heavy scheduled work after explicitly enabled; Cloudflare Cron is disabled in the initial config.

Raw history remains offline; D1 does not need all raw datasets. Workers Free CPU is limited to 10 ms per invocation, so baseline batches are capped at five fixtures and require deployed CPU measurement before live scheduling. Python/XGBoost never executes in a request. D1 Free has a 500 MB per-database cap and 100,000 rows written/day; measure index writes and snapshot retention.

No paid services, production writes or publishing in this implementation run. Zero-cost switches reduce usage but do not replace account-level free plans and hard billing controls. Worker has no live scheduler, no production ID, workers_dev=false, and live integration requires explicit approval and reset verification.

Historical labels remain unverified source records. Accepted means eligible for conservative date-batched research, not externally certified facts. Exclude the entire suspect EPL season; flag all bare timezones; never silently invent kickoffs, scores, or cross-provider identity.

scikit-learn's OpenMP DLL was blocked by Windows Application Control on this machine. Keep the security policy unchanged. Fit multinomial L2 Logistic Regression with NumPy/SciPy L-BFGS, use XGBoost's supported native DMatrix/Booster API, and serialize safe JSON. No pickle deserialization.

Pin the locally verified Wrangler 4.116.0 / Miniflare 4.20260730.0 runtime pair and compatibility date 2026-07-30. The initially resolved newer Wrangler/Miniflare beta could bundle but failed to start its local runtime (`spawn UNKNOWN`). The tested stable pair runs D1 and the Worker successfully. Dependency overrides patch undici/sharp; npm audit is clean. Revalidate compatible runtime upgrades separately rather than silently upgrading this project.
